# UTS Pemrograman Web 1 — Toko Buku Online

Project ini dibuat berdasarkan soal UTS yang diberikan:
- HTML semantik dan valid
- CSS inline, internal, dan external
- JavaScript DOM, validasi form, tabel, modal, alert, dan interaksi UI
- Data dummy menggunakan Array JavaScript pada `js/data.js`

## Cara menjalankan di VS Code
1. Ekstrak folder project.
2. Buka folder `UTS_Pemrograman_Web_1` di VS Code.
3. Buka `login.html`.
4. Jalankan dengan Live Server (disarankan) atau buka langsung `login.html` di browser.
5. Login demo:
   - Email: `admin@bukakita.com`
   - Password: `admin123`

Tidak membutuhkan database, PHP, Node.js, atau internet untuk fungsi utama.
